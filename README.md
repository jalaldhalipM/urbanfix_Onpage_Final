# UrbanFix keyword-mapped website

Static website built from `UrbanFix_Keyword_Mapping_OnPage.xlsx`. This is fictional training content for a Pondicherry home-appliance repair business.

## Publish

Upload the contents of this folder to a repository root, then publish it with GitHub Pages or Render Static Site. Before deployment, replace every `YOUR-SITE-URL` with the actual public origin, without a trailing slash. For example: `https://urbanfix-demo.onrender.com`.
